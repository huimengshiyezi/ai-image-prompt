# 01 · 槽位骨架

用户递过来的想法永远是碎片：`一个赛博朋克女孩` / `秋天的森林，要宫崎骏那种感觉` / `给我做个咖啡海报`。
骨架的唯一作用是把碎片补成一个完整画面，并让你知道**该问什么、什么可以不问**。

本文件合并了两套来源（叶子的 Midjourney 8 要素框架 + 通用 7+2 槽模板），
拆成三层十七槽。**每槽都标了必填度和缺省值** —— 缺省值就是"用户不回答时你直接填什么"。

---

## 一、三层骨架

### A 层 · 主体层

| 槽 | 回答什么 | 必填 | 缺省策略 |
|---|---|---|---|
| A1 主体 | 画面里最主要的是什么（人 / 物 / 景 / 概念）| ✅ 必填 | 问不出来就不动手 —— 没有主体就没有画面 |
| A2 关键特征 | 主体的辨识性特征（外貌、材质、形态、品牌）| ✅ 必填 | 由画面类型给一套通用描述 |
| A3 动作 / 姿态 | 主体在做什么（静物也要写摆放关系）| ⭕ 建议 | 人物默认"自然地站着或坐着，身体朝向略微偏离镜头"；静物默认"居中平放" |
| A4 服装 / 道具 | 穿什么、拿什么、有什么强身份道具 | ⭕ 建议 | 不写；写了就必须写材质和颜色 |

### B 层 · 画面层

| 槽 | 回答什么 | 必填 | 缺省策略 |
|---|---|---|---|
| B1 媒介 / 渲染 | 这是照片、插画、3D、手绘、还是印刷品 | ✅ 必填 | 由画面类型推断，推断不出就问 —— 它决定后面所有槽的写法 |
| B2 风格 | 具体风格 / 参照系 / 艺术家 | ✅ 必填 | 用户没提就给 2-3 个候选让他挑（见 02） |
| B3 场景 / 环境 | 在哪、什么时间、什么天气、背景是什么 | ✅ 必填 | 按画面类型给一个"背景为深色纯色"或"虚化自然背景" |
| B4 光照 | 光源是什么、从哪个方向来、落在哪、阴影什么样 | ⭕ **强建议** | **永远不要留空** —— 见 03 第 1~3 步，AI 生图崩得最多的就是这一槽 |
| B5 色彩 | 主色 + 补色（至少两个色温）| ⭕ 建议 | 从风格族继承；单色系风格除外（如黑白、单色调）。⚠️ ⛔ 不要默认"低饱和冷调" |
| **B5b 影调** | 高调 / 中间调 / 低调 —— 画面整体明暗 | ✅ 必填 | ⭐ **默认中间调**。⛔ 不要默认低调 / 暗调，见 `05` 的「影调」一节 |
| B6 构图 / 景别 | 拍到哪、机位在哪、用什么构图法 | ✅ 必填 | 由画面类型给默认景别；**画幅反向约束景别，这两个必须一起定** |
| B7 情绪 | 观感基调（宁静 / 压迫 / 孤独 / 热烈）| ⭕ 选填 | 不写；**写了就要落到可观察的东西上**，"氛围感"这种词零效果 |

### C 层 · 规格层

| 槽 | 回答什么 | 必填 | 缺省策略 |
|---|---|---|---|
| C1 画幅比例 | 1:1 / 3:4 / 16:9 / 9:16 … | ✅ 必填 | 先定"主体占画幅多大"，再按主体占比给（见下表）|
| C2 质量 / 细节 | 画质词、材质、细节层级 | ⭕ 选填 | 自然语言类模型**默认不堆画质词**（见 05）|
| C3 目标模型 / 语言 | 出给哪个模型、中文还是英文 | ✅ 必填 | 默认中文整段；用户点名 MJ/SD 才切形态（见 04）|
| C4 文字 / 标题 / 落款 | 画面里的标题、文案、手写落款 | ✅ 看用途 | **海报 / 封面 / 产品图 / 信息图 / KV → 主动问文字内容**；纯氛围图 → 默认不加 |
| **C5 影调（明暗）** | 高调 / 中间调 / 低调 | ✅ 必填 | ⚠️ **默认中间调**。⛔ 不要默认低调（见 `05` 的「影调」一节）|

### 画幅按「主体占比」给，不按画面类型给

⛔ **画幅要跟主体大小绑，不是跟题材绑** —— 同一个"人物写真"，
人要占满画面和人在风景里，画幅完全不同：

| 主体占比 | 画幅 | 为什么 |
|---|---|---|
| 特写 / 面部占满 | 3:4 · 4:5 · 1:1 | 竖或方，让主体撑满 |
| 半身 / 中景 | 3:4 · 4:5 · 16:9 | 竖为主 |
| 环境人像（人偏小）| 16:9 | 横幅给环境留位置 |
| 纯风光 / 电影叙事 | 16:9 · 21:9 | ⛔ **21:9 只给明确的风光或电影感需求** |

⛔⛔ **21:9 不要当默认值** —— 它是宽银幕比例，天然把人物压小。
人物图给了 21:9，人就会变成两个小点（这是实战踩过的坑）。

## 二、画面类型路由（先定这个，再填槽）

**第一步永远是判断"这是张什么图"** —— 它一次性决定 B1/B6/C1 的默认值，
也决定后面该重点补哪几个槽。

| 画面类型 | 典型需求 | 重点槽位 | 默认景别 | 默认画幅 |
|---|---|---|---|---|
| **人物肖像 / 写真** | 人像、头像、写真、cos | ⛔ **先问人多大**；B4 光照 | 半身 | 3:4 / 4:5 |
| **角色设定** | 人物设计、三视图、立绘 | A2 / A4 / B2 | 全身 | 2:3 / 3:4 |
| **场景 / 概念图** | 风景、世界观、大场景 | B3 / B4 / B6 | 远景或全景 | 16:9 / 21:9 |
| **产品 / 电商** | 产品图、卖点图、详情页 | A2 材质 / B4 / C1 | 中景或特写 | 1:1 / 4:5 |
| **海报 / KV** | 宣传海报、字体海报、主视觉 | B6 构图 / C1 / C4 | 中景 | 3:4 / 9:16 |
| **信息图 / 图表** | 数据可视化、流程图、科普图 | B6 版式 / C2 文字 | 全幅 | 3:4 / 16:9 |
| **UI / 界面图** | App 界面、网页截图质感 | B6 层级 / C2 | 全幅 | 16:9 / 9:16 |
| **品牌 / Logo** | 标志、辅助图形、周边 | A2 / B2 | 居中 | 1:1 |
| **建筑 / 空间** | 室内、建筑外观、空间设计 | B3 / B4 / B6 透视 | 广角 | 16:9 |
| **插画 / 绘本** | 儿童插画、杂志插图、故事图 | B1 / B2 | 中景 | 4:3 / 1:1 |
| **古风 / 东方** | 中国风、汉服、水墨、神话 | B2 / A4 / B3 | 半身或全景 | 3:4 / 16:9 |
| **食品 / 生活方式** | 美食、咖啡、旅行记录 | B4 / B5 | 近景特写 | 4:5 / 1:1 |

⛔ **前三类都含人物时，第一件事永远是问「人在画面里多大」**（见 SKILL.md 起手第三步）——
它决定景别、画幅、光位，比题材本身更重要。

> ⚠️ 判断不出来时，**不要猜完就往下走** —— 用一句话把两个候选摊给用户：
> "你这张更像 A（人物写真）还是 B（场景氛围图）？这两个的默认构图和光位不一样。"

## 三、每槽的提问模板

提问的硬规则在 SKILL.md 里（每轮 ≤3-4 项、每项必须带默认值、不重复问）。
这里是**每槽问的时候具体怎么开口**。

| 槽 | 问法（带默认建议） |
|---|---|
| A1 主体 | "主体就按你说的「___」来，对吧？还是想换成 ___？" |
| A3 动作 | "我给她设计成「___」，这样比站着更能撑住画面，OK 吗？" |
| A4 服装 | "穿搭我先定「___」——要改风格（比如换成中式 / 未来感）随时说。" |
| B1 媒介 | "出成**照片质感**还是**插画**？这两个出来的完全不是一种东西。" |
| B2 风格 | 给 2-3 个候选，每个一句话说清"出来会是什么样"（不说术语）|
| B4 光照 | "光我打算这么打：___（光源 + 方向 + 落在哪）。要换方向吗？" |
| B5 色彩 | "整体色调走「___ + ___」，冷的那半用来提亮画面。" |
| B6 构图 | "画幅我定 ___，机位 ___ —— 这两个绑在一起，改一个另一个也要动。" |
| C1 画幅 | "你是发___（平台）对吧？那我按 ___ 出。" |

**反例（不要这么问）**：
- ❌ "请问你想要什么风格？" —— 开放式问题，用户答不出来，等于把活推回去
- ❌ "光照、色彩、构图、情绪分别要什么样的？" —— 一次四个开放式问题，用户会跑
- ❌ "你确定要 16:9 吗？" —— 除非命中红线，不要问确认题

## 四、装配顺序（怎么写成一整段）

自然语言类模型吃**整段句**，顺序不是随便排的 —— **前面的句子会盖过后面的**。
顺序依据 OpenAI 官方给图像模型的推荐读法：**意图 → 场景/背景 → 主体 → 关键细节 → 文字 → 约束**。

按下面的顺序拼，每一条都是一个有主谓的句子，不要写成逗号分隔的词组。

```
① 意图 / 用途     —— 第一句就说这是什么图、干什么用
② 画幅 + 景别     —— 多比、拍到哪、主体占画幅多大
③ 场景 + 光源位置 —— 在哪、什么时间、光源是什么、架在哪（光源写在场景句里）
④ 主体            —— 是谁/是什么，关键特征，在做什么，穿什么
⑤ 光的落点        —— 光打在主体上落在哪，明暗怎么分
⑥ 色彩 + 材质     —— 主色 + 第二色温在哪；材质与微纹理
⑦ 文字（可选）    —— 手写落款 / 标题的位置和形态
⑧ 收尾            —— 一句约束，2~3 项
```

### 四条顺序规则

- ⛔⛔ **第一句必须写"这是什么图"，不能直接写主体。**
  ✅ `为自媒体封面做的一张 3:4 竖幅人像照片` ／ `一张电影感的双人特写照片`
  ⛔ `一个年轻女性……`
  开头的词会**选中模型的"模式"** —— 这是提升最大的单点改动。
- ⛔ **场景写在主体之前。** 官方推荐先把"这是在哪、背景是什么"交代清楚，再放主体。
  实测主体和场景互换影响相对小，但**意图打头 + 场景先于主体**是官方顺序。
- ⛔ **光源位置写在场景句里**，不要单独起一句写"光照"。
  光是靠场景写出来的，不是靠形容词 ——
  "身后是敞开的店门和门外的街道"能出逆光，"身后是干净的墙面"出不来（墙把光源挡在画框外了）。
- ⛔ **画幅和景别必须相邻**：它们互相约束，隔开写会得到自相矛盾的组合。

### 装配示例

> 输入碎片：`赛博朋克女孩，雨夜`

```
一张 9:16 的竖幅电影感人像照片，从腰往上入镜。        ← ① 意图 + ② 画幅景别

一条狭窄的雨夜巷道，两侧是密排的霓虹招牌和自动贩卖机，  ← ③ 场景 + 光源位置
路面是湿润的沥青、积着水洼，远处收进深青色的街景；
一台自动贩卖机的冷白灯箱就在她正前方偏下的位置。

一个年轻女性站在画面中心偏右，黑色短发被雨打湿贴在脸侧， ← ④ 主体
穿一件表面有反光的深色连帽夹克，正微微抬头看向镜头。

灯箱的冷白光从下往上打亮她的下颌和鼻梁，              ← ⑤ 光的落点
鼻侧留下一小块亮斑，另外半张脸落在柔和的暗部里；
右后方一块暖橘色霓虹灯牌在头发外缘勾出一条暖色亮边。

画面整体是青蓝冷调，唯一的暖色是那块霓虹灯牌和地面的倒影。 ← ⑥ 色彩 + 材质
雨丝在空气里被灯光照成一条条亮线，湿润的路面把霓虹拉成长长的反光带。

画面里只有她一个人，双手五指完整，没有文字和水印。      ← ⑧ 收尾
```

对照槽位：① 意图 ✅ / ② 画幅景别 ✅ / ③ 场景+光源 ✅ / ④ 主体 ✅ / ⑤ 光落点 ✅ /
⑥ 色彩材质 ✅ / ⑧ 收尾 ✅（⑦ 文字没要，跳过）。
注意没有任何一个槽是靠堆形容词完成的 —— 每个槽都写成了**具体的东西**。

## 五、缺省值总表（用户不回答时直接填）

⛔ **说明：这张表是"实在问不出来"时的兜底**，不是"不用问"的借口。
有具体人物的图，**"人多大"必须先问**（SKILL.md 起手第三步），不要直接查这张表。

| 场景 | 缺省 |
|---|---|
| **没说人多大**（人物图）| ⛔ **这一项不许查表，必须问**。实在问不出来 → 半身、两人占画面中段、能看清脸 |
| 没说主体多大（非人物）| 产品 → 中景；场景 → 全景 |
| 没说画幅 | 按主体占比给（见上）：特写 3:4 · 半身 3:4 · 环境人像 16:9。⛔ 不要默认 21:9 |
| 没说光照 | `一个明确方向的主光从侧前方 45° 照进来，主体被照亮的一侧是亮的、另一侧落在浅灰色的柔和暗部里；整体曝光正常偏亮，暗部里仍有层次`。<br>⛔ **不要默认"大面积散射光 / 均匀柔光"** —— 那会把脸照平，亮度上去了美感下来了（见 `05` 的「亮和美是两个独立的轴」一节）。<br>⛔ 也不要"环境压暗" |
| 没说影调 | ⭐ **中间调**（有亮有暗但不极端）。⛔ 不要默认低调 / 暗调 |
| 没说色彩 | 暖色主光 + 冷色环境。⚠️ ⛔ **不要默认"蓝灰冷调低饱和"** —— 那是一套完整的暗调配方，不经确认给出去图必暗 |
| 没说风格 | 见 02 的"拿不准就用这三个" |
| 没说质量词 | 自然语言类模型**不加**；MJ/SD 加一行通用质量词（见 05）|
| 没说语言 | 中文整段 |
| 没说文字 | ⭐ **看用途**：海报 / 封面 / 产品图 / 信息图 / KV → **主动问文字内容**；纯人物 / 氛围图 → 不加 |
| 没说情绪 | 不写。宁缺毋滥 —— "氛围感"这类词会被模型当噪声 |

⛔ **唯一不允许留空的槽是 B4 光照**。光照留空 = 模型自己随机决定光位 = 十张里九张脸是平的。

⛔ **两件事永远不许用兜底代替提问**：
1. **人物图的人多大**（决定画面类型）
2. **感受词的实现路径**（"朦胧感"要远影还是要柔焦近景）
